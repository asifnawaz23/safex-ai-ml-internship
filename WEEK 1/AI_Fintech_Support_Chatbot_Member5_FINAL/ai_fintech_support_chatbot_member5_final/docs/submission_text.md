## Contribution Summary
I developed the fintech chatbot's intent-understanding module using a Hugging Face zero-shot Transformer model. The module validates user input, classifies customer-support messages into fintech support categories, returns confidence scores, and routes predictions to controlled support responses. I also created a browser demo using FastAPI, 15 labelled test cases, automated PASS/FAIL evaluation, error handling, and project documentation.

## Key Features
- Hugging Face Transformers zero-shot classification
- 9 fintech support intents
- Browser-based chatbot demo
- REST API endpoint
- Confidence-based fallback
- Input/error handling
- 15 automated test cases
- Safe response templates
- README and technical write-up
