# Scope Document

## In Scope
- Sentiment analysis (Positive, Neutral, Negative) using local CPU-based Hugging Face models.
- Confidence scoring natively returned by the model.
- Feedback theme classification via transparent rule-based logic.
- CSV batch upload and processing with validation.
- Aggregated analytics generation (percentages, counts, trend mappings).
- A professional React-based dashboard for data visualization.
- Interactive filtering by date, sentiment, and theme.
- Comprehensive automated testing using pytest.
- Full technical documentation.

## Out of Scope
- Medical diagnosis or clinical decision making.
- Ingestion, processing, or storage of real patient medical records (PHI).
- HIPAA, GDPR, or SOC2 compliance certification (as this is a demonstration prototype).
- GPU-accelerated inference.
- Cloud deployment infrastructure (e.g., Kubernetes, Docker swarms).
- Fine-tuning the NLP model specifically on dental literature.
