# Changelog

## v0.1
Initial project structure. Repository folders created.

Added Hugging Face sentiment engine utilizing `distilbert-base-uncased-finetuned-sst-2-english`. Constructed single-instance loader and application-layer Neutral fallback.

Added CSV processing and validation. Built pandas logic for handling file memory bytes and dropping empty records.

Added rule-based theme detection for dental domains (Staff, Dentist, Wait Time, etc.).

Added analytics engine. Calculates dynamic percentages, counts, and insight generation from dataset loops.

## v0.6
Added React dashboard. Configured Vite, Tailwind, Recharts. Created layout structure with Sidebar and React Router.

## v0.7

Final QA and documentation. Complete suite of README, PRD, Scope, Architecture, Testing, and UX Guidelines finalized.
