# Privacy

**Important Note for Reviewers and Users:**

This project, DentalSense AI, is a demonstration and portfolio project.

- **No Real Patient Data:** All sample data provided (`data/sample_feedback.csv`) is 100% synthetic and automatically generated. It does not reflect any real individuals, clinics, or events.
- **No PHI Processing:** The system is not designed to ingest, process, or store Protected Health Information (PHI). 
- **No Medical Advice:** The sentiment model and theme categorizations do not constitute clinical guidance, diagnosis, or treatment recommendations.
- **Not HIPAA Compliant:** This system lacks the rigorous audit logging, encryption, and access controls required for a production healthcare environment. Do not use this software with real patient data.
